# The Axiom Manifesto

Traditional operating systems were designed for a world where hardware was scarce, networks were trusted, and a human sat at a physical terminal. They manage resources. 

Axiom does not manage resources. Axiom manages cryptographic causality.

We reject the fundamental compromises of legacy architectures:
1. **We reject the Administrator.** There is no `root`, no `sudo`, and no bypass. Authority is not derived from who you are; it is derived strictly from the cryptographic capabilities you hold.
2. **We reject the Hardware Boundary.** The network is not an external peripheral. It is a transport layer for the Capability Graph. Local and remote objects operate under the exact same physics.
3. **We reject Global State.** There is no single objective reality. There is only the mathematically verifiable lineage of delegations. If a state cannot be cryptographically proven, it does not exist.
4. **We reject Mutable History.** Corruption is not a condition to be patched; it is an ontological paradox. Axiom heals by collapsing corrupted states and replaying verifiable history.

In Axiom, everything is a capability. The operating system is merely the engine that proves them true.
