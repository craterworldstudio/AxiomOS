# ADR-010 — Sovereign Screen Takeover, Object-Capability Console Subsystem, and Text-Based GUI Canvas

## Status

Accepted (Phase 7A Milestone Verified)

## Context

During early boot, the microkernel utilizes the UEFI GOP framebuffer to render diagnostic selftest outputs (54 automated tests). However, once selftests pass, the operating system must transition out of the diagnostic harness and hand complete visual and operational control to user space.

In traditional monolithic kernels, the display driver and terminal emulator reside inside Ring 0 (`/dev/fb0`, `tty0`, DRM/KMS). In a sovereign capability microkernel:
1. Ring 0 does not implement a complex window manager or GUI server.
2. The display/console must be accessed via explicit object capability invocation (`ROOT_SLOT_CONSOLE = 5`).
3. The root user task (`axiom_genesis`, PID 1) must be able to clear diagnostic logs, render a high-resolution text-based GUI canvas, and drive user-mode formatting.
4. The system must maintain native 1280x720 16:9 widescreen GOP resolution without distortion.

## Decision

1. **Console Object Capability (`ROOT_SLOT_CONSOLE = 5`)**:
   - The microkernel registers the GOP display as a capability-backed service accessible through endpoint invocation:
     - `OP_CONSOLE_WRITE = 6`: Writes packed ASCII byte chunks (up to 8 bytes per syscall).
     - `OP_CONSOLE_CLEAR = 7`: Blanks the screen buffer to background color.
     - `OP_CONSOLE_BANNER = 8`: Clears the screen and paints the 28-pixel high obsidian status header.
     - `OP_CONSOLE_COLOR = 9`: Sets text foreground and background RGB colors (`0x00RRGGBB`).
   - Authority is gated by `Rights::WRITE` on slot 5.

2. **Obsidian & Electric Cyan Status Header**:
   - `Console::draw_banner()` renders a 28-pixel high obsidian slate status bar (`#161B22`) across all 1280 horizontal pixels.
   - Accented by a single-pixel electric cyan border (`#00D2FF`) at $y = 28$.
   - Displays real-time operational status:
     `[ AXIOM OS ]  v0.2.0-alpha   |   PID 1: Genesis   |   Mode: Sovereign Ring 3   |   Display: 1280x720 16:9`
   - Automatically repositions the cursor below the header at Row 3, Column 2.

3. **User-Space Capability Print Pipeline (`libaxiom::console`)**:
   - `ConsoleWriter` implements `core::fmt::Write`.
   - String slices from `write!` and `println!` are sliced into 8-byte chunks, packed into register `RDX`, and delivered to the microkernel via hardware `syscall` instructions.
   - Enables standard Rust string formatting (`format_args!`, `{:#x}`, `{}`, etc.) entirely within Ring 3 without standard library dependencies.

4. **Sovereign Screen Takeover Sequence**:
   - Upon completing the 54-test suite, the supervisor thread resets Genesis execution context (`tcb_e.state = Ready`, `frame_kind = Interrupt`, forged user stack).
   - The supervisor signals Genesis via mailbox flag `2`.
   - Genesis enters live takeover branch:
     - Invokes `ConsoleWriter::draw_banner()`.
     - Prints the AxiomOS sovereign core substrate welcome banner and security status indicators in crisp silver, emerald green, and gold.
     - Emits the sovereign interactive root prompt: `root@axiom:~# `.
     - Enters the user-space idle/heartbeat spin loop.

## Consequences

- **Positive**: The selftest boot screen is completely wiped and cleanly replaced by the sovereign Genesis canvas.
- **Positive**: Zero ambient display access; display control is an attenuable capability that can be delegated or restricted to child processes.
